# Icon attribution

## Toolbox tool icons (from Pinta)

Most toolbox icons are scalable symbolic SVGs from
[Pinta](https://github.com/PintaProject/Pinta)
(`Pinta.Resources/icons/hicolor/scalable/actions/`).

Pinta documents those symbolic icons as a mix of:

- Paint.NET / Pinta / Microsoft Fluent UI System Icons — MIT
- Google Material Icons — Apache License 2.0
- Some GIMP icons — Creative Commons Attribution 4.0 International (CC-BY-4.0)

Those licenses can ship in a BSD-licensed application with this attribution.
This tree does not include GIMP raster/GPL assets, Adwaita/CC-BY-SA theme
icons, KolourPaint/Breeze (LGPL), or Krita (GPL) icons.

See Pinta’s `Pinta.Resources/icons/hicolor/scalable/readme.md` and
`Pinta.Resources/icons/pinta-icons.md`.

## Original Lunduke Paint icons

Pinta has no spray, curve, or polyline tool icons. These 16×16 symbolic
SVGs are original Lunduke Paint artwork (public domain / BSD):

- `tool-spray-symbolic.svg`
- `tool-curve-symbolic.svg`
- `tool-polyline-symbolic.svg`

## Application icon (0.5-10)

`org.lunduke.LundukePaint` hicolor PNGs (16–512) plus archival master
`org.lunduke.LundukePaint-master.png` (1408×1408 RGBA). Rasters are
authoritative; no scalable app SVG is installed (a placeholder SVG would
outrank PNG in the theme lookup).
